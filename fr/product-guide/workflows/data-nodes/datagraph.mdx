Le Data Node Objet Datagraph apporte à votre Workflow les résultats d'un Objet publié.

Sa description est *Exécutez une requête d'objet Datagraph et exposez ses résultats dans le workflow.*

![Data Node Objet Datagraph avec un Objet publié sélectionné et son paramètre renseigné](/images/workflows/node-datagraph-query.png)

## Vue d'ensemble

Le Data Node **Objet Datagraph** (une étape qui récupère des données externes) rend disponibles aux Nodes suivants les résultats d'un Objet [Datagraph](/fr/product-guide/datahub/datagraph) publié.

Utilisez-le lorsque vous avez besoin de données issues de plusieurs Datasources. L'Objet Datagraph les rassemble pour que votre Workflow puisse utiliser les résultats.

<Warning>
  Le Datagraph est en bêta. Seuls les administrateurs techniques peuvent configurer les nœuds d'interrogation d'objet Datagraph. Demandez à votre administrateur si le Node apparaît en lecture seule.
</Warning>

## Ajouter le Node

1. Ouvrez votre Workflow dans l'[éditeur de Workflow](/fr/product-guide/workflows/editor).
2. Survolez le bouton **Data** (icône de base de données) dans la barre d'outils du bas.
3. Cliquez sur **Objet Datagraph**.

![Menu Data de l'éditeur de Workflow avec l'option Objet Datagraph en bas de la liste](/images/workflows/node-picker-data-datagraph.png)

## Configurer le Node

1. Choisissez un **Objet** dans **Sélectionner un objet publié**. Seuls les Objets publiés apparaissent.
2. Renseignez chaque champ sous **Paramètres de l'objet**.
3. Cliquez sur **Confirmer**.

Le Node affiche alors sur le canvas le nom de l'Objet sélectionné.

![Data Node Objet Datagraph sur le canvas du Workflow, affichant le nom de l'Objet sélectionné](/images/workflows/node-datagraph-query-canvas.png)

### Paramètres de l'objet

La courte description de chaque paramètre apparaît au-dessus de son champ. Saisissez une valeur fixe ou choisissez une valeur du Workflow.

![Champ de paramètre Objet Datagraph avec son type, sa courte description et les valeurs du Workflow disponibles](/images/workflows/node-datagraph-query-parameter.png)

<Tip>
  Utilisez une valeur du Workflow, par exemple un identifiant de personne capté avec un Node [URL Parameter](/fr/product-guide/workflows/data-nodes/url-parameter), pour personnaliser les résultats de chaque destinataire.
</Tip>

### Limite de résultats

Par défaut, le champ **Limite de résultats** est masqué. Il apparaît uniquement si un administrateur technique active **Objet Datagraph : limite de résultats** dans les paramètres des Workflows → onglet **Fonctionnalités**.

Lorsqu'elle est disponible, la limite accepte de 1 à 200 lignes.

Gardez une limite proche de ce que votre [Content](/fr/product-guide/contents/overview) affiche. Demander trois produits quand vous en affichez trois accélère votre Workflow.

## Utiliser les données ensuite

Les champs renvoyés par l'Objet deviennent disponibles pour les Nodes suivants, via le **Variable Picker**. Vous pouvez les utiliser dans votre Content, ou dans une [Condition](/fr/product-guide/workflows/logic-nodes/conditions) pour adapter ce que chaque personne voit.

<Info>
  Le sélecteur vide indique *Aucun objet publié n'est disponible pour le moment.* Demandez à votre équipe data de publier un Objet dans **DataHub → Datagraph → Objets**.
</Info>

## Bonnes pratiques

- Prévisualisez d'abord l'Objet dans le DataHub pour connaître les champs renvoyés. **Ouvrir l'objet dans Datahub** l'ouvre depuis le champ Objet.
- Renseignez chaque paramètre. Un Objet dont un paramètre obligatoire manque ne renvoie rien.
- Rouvrez le Node après la publication d'une nouvelle version de l'Objet pour vérifier les paramètres.

## Utiliser des familles d'objets dans les Contents

Une famille d'objets permet à un Workflow de fournir n'importe quel Objet publié qui en fait partie. Sélectionnez la famille comme source lors du [binding des données du Content](/fr/product-guide/contents/data-binding).
