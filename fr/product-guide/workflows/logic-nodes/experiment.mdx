![Node Expérimentation avec ses branches de variantes dans un Workflow](/images/workflows/node-experiment.png)

Utilisez le Node Expérimentation (un Logic Node qui répartit le trafic) pour transformer les variantes d'une expérimentation Analytics en Branches de Workflow. Chaque variante devient un Node **Variante** (une Branch) qui indique la part de trafic qu'elle reçoit actuellement.

Avant le démarrage, le Traitement d'un Groupe témoin global ou la Référence d'un Test A/B continu affiche 100 %.

## Ajouter un Node Expérimentation

![Panneau Expérimentation avec la recherche, les expérimentations disponibles, les barres de répartition et les commandes de sélection](/images/workflows/node-experiment-configuration.png)

1. Dans le sélecteur de Nodes du Workflow, choisissez **Expérimentation**.
2. Recherchez une expérimentation **Prête** ou **En cours**, puis sélectionnez sa carte.
3. Sélectionnez **Confirmer** pour ajouter le Node Expérimentation.

Seules les expérimentations **Prêtes** et **En cours** sont répertoriées. Si aucune n'est disponible, utilisez **Créer une expérimentation** pour ouvrir Analytics.

<Tip>
  Si la publication signale un problème de variante sur ce Node, rouvrez-le et sélectionnez à nouveau l'expérimentation. Ses Branches sont recréées à partir des variantes de l'expérimentation.
</Tip>

## Après la conclusion

La variante conservée porte la mention **Gagnante**, et le Node lui envoie tout le trafic.

Une expérimentation terminée reste sur le Node et continue d'orienter le trafic vers son résultat. Vous ne pouvez pas la sélectionner pour un nouveau Node.

Si l'expérimentation est archivée ou introuvable, le Node affiche **Expérimentation indisponible**. Il envoie tout le trafic vers le **Traitement** d'un Groupe témoin global ou la **Référence** d'un Test A/B continu. Si elle était déjà terminée lors de la dernière publication du Workflow, il envoie plutôt le trafic vers la variante conservée.
