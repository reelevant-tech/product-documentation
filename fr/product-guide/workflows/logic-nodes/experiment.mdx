![Node Expérimentation avec ses branches de variantes dans un Workflow](/images/workflows/node-experiment.png)

Utilisez le Node Expérimentation (un Logic Node qui répartit le trafic) pour transformer les variantes d'une expérimentation Analytics en Branches de Workflow. Chaque variante devient un Node **Variante** (une Branch) qui affiche son **Allocation**.

## Ajouter un Node Expérimentation

![Panneau Expérimentation avec la recherche, les expérimentations disponibles, les barres de répartition et les commandes de sélection](/images/workflows/node-experiment-configuration.png)

1. Dans le sélecteur de Nodes du Workflow, choisissez **Expérimentation**.
2. Recherchez une expérimentation **Prête** ou **En cours**, puis sélectionnez sa carte.
3. Sélectionnez **Confirmer** pour ajouter le Node Expérimentation.

Seules les expérimentations **Prêtes** et **En cours** sont répertoriées. Si aucune n'est disponible, utilisez **Créer une expérimentation** pour ouvrir Analytics.

## Associer les branches aux variantes

Avant de publier, associez chaque branche à une variante différente. Une branche sans variante ou une variante répétée bloque la publication.

Pour corriger l'association, rouvrez le Node Expérimentation et sélectionnez à nouveau l'expérimentation. Cela recrée ses branches à partir de ses variantes.

La publication échoue aussi si l'expérimentation ne peut plus être rattachée. Choisissez plutôt une expérimentation **Prête** ou **En cours**.

## Après la conclusion

La variante conservée porte la mention **Gagnante**, et le Node lui envoie tout le trafic.

Si l'expérimentation est **Archivée** ou introuvable, le Node affiche **Expérimentation indisponible**.
