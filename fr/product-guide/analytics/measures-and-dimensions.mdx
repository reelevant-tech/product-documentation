## Vue d'ensemble

Cette référence liste les mesures et dimensions que vous pouvez utiliser dans Data Exploration.

## Mesures

### Mesures des événements de Workflow

| Mesure | Description | Ancien nom |
|---|---|---|
| Temps moyen de génération du contenu | Temps moyen pour afficher un Content (un visuel conçu dans le Content Editor). | — |
| Individus touchés | Individus uniques touchés sur un Channel (un mode de diffusion d'un Workflow). | Unique Opener Count |
| Nombre total d'impressions | Nombre de fois qu'un message contenant au moins un Content Reelevant a été vu. | Total Opening Count |
| Impressions par individu touché | Nombre moyen d'impressions par individu touché. | Repeat Content Exposition Per User |
| Affichage total | Nombre de Contents Reelevant affichés. Une impression peut contenir plusieurs Contents. | — |
| Clic total | Nombre de clics sur du Content Reelevant. | — |
| Nombre de cliqueur unique | Nombre d'individus uniques ayant cliqué sur du Content Reelevant. | — |
| Moyenne de clic par utilisateur | Nombre moyen de clics par individu. | — |
| Impressions individualisées | Impressions dans lesquelles au moins un Content individualisé a été vu. | Individualized Opening Count |
| Nombre d'affichage individualisé | Nombre de Contents individualisés affichés. | — |
| Taux d'affichage individualisé | Part des Contents affichés qui étaient individualisés. | — |
| Individus touchés (individualisé) | Individus touchés ayant vu au moins un Content individualisé. | Unique Individualized Opener |
| Taux d'individus touchés (individualisé) | Part des individus touchés ayant vu du Content individualisé. | Unique Individualized Opener Rate |
| Taux de clic (par impression) | Nombre total de clics divisé par le nombre total d'impressions. | Click To Open Rate |
| Taux de clic (individus uniques) | Cliqueurs uniques divisés par individus touchés. | Clicker to Opener Rate |

### Mesures des événements d'achat

| Mesure | Description |
|---|---|
| Total Conversion Count | Nombre de conversions ayant suivi un clic sur un Content Reelevant. |
| Unique Buyer Count | Nombre de personnes différentes ayant acheté au moins une fois. |
| Average Order Value | Valeur moyenne des commandes pour les conversions. |
| Total Revenue | Chiffre d'affaires généré par les conversions. |
| Average Revenue Per Buyer | Chiffre d'affaires moyen généré par acheteur. |
| Order Count Per Buyer | Nombre de fois où une personne répète ses achats, en moyenne. |
| Time To Purchase From Click | Temps moyen entre un clic sur un Content Reelevant et l'achat. |
| Reference Count | Nombre total de références produits dans les transactions. |
| Average Reference Count Per Basket | Nombre moyen de références produits par transaction. |

### Mesures dérivées

| Mesure | Description |
|---|---|
| Conversion Rate | Conversions par clic. |
| Unique Conversion Rate | Taux de conversion pour les individus uniques. |
| Click Uplift by Individualized Content | Clics moins ce que seul le Content par défaut aurait apporté. |
| Conversions Uplift by Individualized Content | Conversions moins celles qui auraient été apportées si seul le Content par défaut avait été affiché. |
| Revenue Uplift by Individualized Content | Chiffre d'affaires moins celui qui aurait été apporté si seul le Content par défaut avait été affiché. |

#### Valeurs du code de retour d'exécution

Cette dimension indique si le Runner (le service qui construit votre Content) a terminé le Workflow. La plupart des lignes sont vides : tout s'est bien passé.

| Code | Signification |
|---|---|
| Vide | Le Workflow est allé jusqu'au bout. |
| 3501 | Le Workflow s'est arrêté avant d'atteindre un Output Node (la dernière étape d'une branche). Le visuel par défaut a été affiché. |
| 3502 | Un Node a échoué mais la branche s'est terminée. Votre Content a bien été affiché. |
| 3503 | Un clic n'a pas pu être associé à un lien de destination. |

Une part importante de 3501 ou 3502 signale généralement une Datasource qui ne répond plus. Transmettez le nom du Workflow et le code à votre Technical Account Manager.

## Combiner mesures et dimensions

<Warning>
  Évitez de mélanger les mesures des événements de Workflow avec les dimensions des événements d'achat. Elles décrivent des parties différentes de vos données.
</Warning>

<Info>
  Lorsque vous utilisez Workflow Branch, ajoutez aussi Content Name ou Workflow Name. Cela rend le résultat plus facile à lire.
</Info>

<Info>
  Lorsque vous utilisez URL Parameter Value, ajoutez un filtre de paramètre d'URL. Cela permet de garder les résultats centrés sur un seul paramètre.
</Info>

<Info>
  Pour une vue plus complète du comportement au moment de l'ouverture, consultez [Mise en cache et proxys des clients de messagerie](/fr/advanced-guide/email-rendering/caching-and-proxies).
</Info>
